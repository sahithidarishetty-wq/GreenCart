🛒 GreenCart – Online Grocery Shopping Webpage

📌 About the Project

GreenCart is a responsive online grocery shopping webpage designed to provide users with a simple and user-friendly shopping experience.
The project includes product categories, navigation, registration/login pages, and interactive webpage elements.

🚀 Features

- 🏠 Home page
- 🛍️ Product categories
- 🔐 Registration page
- 🔑 Login page
- 📱 Responsive design
- 🎨 Clean and user-friendly interface
- ⚡ Interactive elements using JavaScript

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
